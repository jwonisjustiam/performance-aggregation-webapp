# 네이버 쇼핑라이브 통계 수집기

네이버 아이디, 비밀번호, 로그인 쿠키를 웹 앱이나 외부 서버에 저장하지 않습니다. 로그인된 Chrome에서 사용자가 조회한 종료 방송의 통계 화면을 차례로 열어 `라이브중 시청수`, `유니크 결제자수`, `결제 상품수`를 CSV로 내려받습니다.

## 계정 구분

- 외장하드: `삼성공식파트너 쇼마젠시`
- 웨어러블: `삼성파트너 쇼마젠시`

## 사용 순서

1. Chrome 확장 프로그램 관리 화면에서 개발자 모드를 켭니다.
2. `압축해제된 확장 프로그램을 로드합니다`를 누르고 이 폴더를 선택합니다.
3. 스마트스토어센터에서 작업에 맞는 스토어로 이동합니다.
4. `스토어관리 → 쇼핑라이브 숏클립 등록 → 관리 페이지로 이동 → 라이브`로 들어갑니다.
5. 날짜를 선택하고 `조회`를 누릅니다.
6. 확장 프로그램을 열고 현재 스토어를 선택한 뒤 `현재 조회 목록 통계 수집`을 누릅니다.
7. 내려받은 `naver_live_stats_YYYYMMDD.csv`를 실적 취합 앱의 `네이버 쇼핑라이브 통계 연결`에 업로드합니다.

네이버 화면 구조가 변경되면 수집기가 값을 찾지 못할 수 있습니다. CSV에 네이버 로그인 정보나 쿠키는 포함되지 않습니다.
