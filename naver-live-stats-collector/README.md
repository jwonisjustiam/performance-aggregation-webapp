# 네이버 쇼핑라이브 통계 수집기

네이버 아이디, 비밀번호, 로그인 쿠키를 웹 앱이나 외부 서버에 저장하지 않습니다. 로그인된 Chrome에서 사용자가 조회한 종료 방송의 통계 화면을 차례로 열어 `시청/알림 통계` 박스의 `시청수`, `유니크 결제자수`, `결제 상품수`를 CSV로 내려받습니다.

## 계정 구분

- 외장하드: `삼성공식파트너 쇼마젠시`
- 웨어러블: `삼성파트너 쇼마젠시`

## 사용 순서

1. Chrome 확장 프로그램 관리 화면에서 개발자 모드를 켭니다.
2. `압축해제된 확장 프로그램을 로드합니다`를 누르고 이 폴더를 선택합니다.
3. 스마트스토어센터에서 작업에 맞는 스토어로 이동합니다.
4. `스토어관리 → 쇼핑라이브 숏클립 등록 → 관리 페이지로 이동 → 라이브`로 들어갑니다.
5. 날짜를 선택하고 `조회`를 누릅니다.
6. 확장 프로그램을 열고 현재 스토어를 선택한 뒤 `현재 조회 목록 통계 수집`을 누릅니다.
7. 내려받은 `naver_live_stats_YYYYMMDD.csv`를 실적 취합 앱의 `네이버 쇼핑라이브 통계 연결`에 업로드합니다.

## 오류가 표시될 때

- `Receiving end does not exist`: `chrome://extensions`에서 수집기의 새로고침 버튼을 누른 뒤 네이버 목록 탭도 새로고침합니다. 0.1.1부터는 필요한 경우 수집 코드를 자동으로 연결합니다.
- `통계 링크를 찾지 못했습니다`: 날짜 조회를 마친 뒤 목록에 종료 방송의 `통계` 버튼이 실제로 표시되는지 확인합니다. 0.1.2부터 네이버의 현재 카드형 목록 구조도 인식합니다.
- `현재 통계 계정이 아닙니다`: 네이버 통계 상세 화면에는 스토어명이 노출되지 않아 생기던 잘못된 오류이며 0.1.3에서 제거했습니다. 수집 전 사용자가 팝업에서 현재 로그인한 업무 계정을 직접 선택합니다.
- `라이브 통계 화면을 찾지 못했습니다`: 통계 본문보다 공통 메뉴의 `라이브 통계 활용법`이 먼저 나타날 때 생기던 로딩 순서 오류이며 0.1.4에서 `라이브 상태를 선택하세요` 메뉴가 실제로 나타날 때까지 기다리도록 수정했습니다.
- 모든 방송의 시청수가 동일한 큰 숫자로 저장됨: 상단 채널 전체 누적 시청수를 먼저 읽던 오류이며 0.1.5에서 각 방송의 `시청/알림 통계` 박스 안 `시청수`만 읽도록 수정했습니다. 0.1.6부터 CSV 열 이름도 `시청수`로 표시합니다. `유니크 결제자수`는 `결제 통계` 박스의 `결제 상품수 6개 (4명)` 같은 표기에서 괄호 안 인원수입니다.

네이버 화면 구조가 변경되면 수집기가 값을 찾지 못할 수 있습니다. CSV에 네이버 로그인 정보나 쿠키는 포함되지 않습니다.
